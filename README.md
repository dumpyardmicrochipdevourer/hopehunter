# hhbot

Telegram-бот автооткликов на hh.ru. По правилам с ключевыми словами ищет свежие вакансии и откликается
выбранным резюме с сопроводительным письмом — сам или после подтверждения кнопкой. Весь интерфейс в боте.

## Риски

У hh нет открытого API для откликов. Бот ходит на сайт от имени пользователя теми же запросами, что и
браузер, с его сессионными куками. Это нарушает пользовательское соглашение hh: возможны капча и
блокировка аккаунта. Поэтому в боте есть и не отключаются:

- дневной лимит откликов на правило (по умолчанию 30);
- случайная пауза 30–90 с между автооткликами, не больше трёх за проход;
- работа только с 09:00 до 21:00;
- при капче или суточном лимите hh — стоп всех откликов пользователя до завтра.

Новое правило создаётся выключенным и в режиме подтверждения.

## Пользователю

`/start` или `/menu` — главное меню, `/cancel` — прервать ввод.

| Раздел | Что там |
|---|---|
| Аккаунт hh | Подключение сессии: значение куки `hhtoken` из браузера. Сообщение с ним бот удаляет, в базе оно зашифровано |
| Правила | Ключевые слова, минус-слова, регион, зарплата, опыт, удалёнка, стоп-лист компаний, резюме, письмо, режим, лимит. «Проверить сейчас» показывает, что правило найдёт, ничего не отправляя |
| Письма | Шаблоны с алиасами `[company_name]`, `[vacancy_name]`, `[salary]`, `[city]`, `[my_name]`; предпросмотр на настоящей вакансии |
| Статистика | Счётчики и последние отклики |

Режимы правила: **авто** — бот откликается сам и сообщает; **подтверждение** — присылает карточку с
кнопками «Откликнуться / Пропустить». Вакансии с тестом работодателя всегда приходят ссылкой.

## Админу

`/whitelist_add <user>`, `/whitelist_remove <user>`, `/whitelist_list`. Админы — `BOT_ADMIN_USERNAMES`.
Удаление из вайтлиста стирает сессию hh, правила и письма человека; журнал откликов остаётся.

## Запуск

```bash
cp .env.example .env   # заполнить; HH_COOKIE_KEY: openssl rand -base64 32
docker compose up -d --build
```

Настройки сканера и их значения по умолчанию — в `src/main/resources/application.properties`.

## Что проверено, а что нет

Поиск вакансий проверен на живом сайте. Список резюме и сам отклик требуют залогиненной сессии и
написаны по известному поведению сайта: первый запуск с настоящим аккаунтом — в режиме подтверждения,
на одной вакансии. Весь обмен с hh живёт в `hh/HhWebGateway`; если сайт изменится, чинить там.
